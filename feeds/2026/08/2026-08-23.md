  - Why it matters: [Cursor plugins](https://github.com/cursor/plugins) defines an official extension contract, while [AI Memory](https://github.com/akitaonrails/ai-memory) targets long-term context and vendor handoff for coding CLIs.

  - Boundary: extension power needs explicit permissions; portable memory needs explicit custody and redaction.

  - Why it matters: [Superpowers](https://github.com/obra/superpowers) packages an opinionated cross-agent workflow rather than one task module. Builders should compare outcome quality and context cost, not repository size.
  - Signal: single segment; attention_heat 74, builder_fit 96.

## Builder Takeaways

- Build: run one existing task with a focused skill and a baseline prompt; compare accepted output, interventions, context size, and test evidence.
- Study: compare skills, methodology, plugins, memory, and harnesses as separate contracts rather than one agent stack.
- Ignore: star velocity, follower-adjusted reach, or multi-agent count as substitutes for a fixed-task receipt.
