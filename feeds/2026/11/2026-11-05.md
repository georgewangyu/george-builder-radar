A useful test would compare consistent edits on the same asset and total iteration cost.

## Builder Takeaways

- Build: evaluate one existing task with a fixed input, observable completion criteria and total iteration cost before changing a model or tool.
- Study: benchmark comparison sets, model licenses, patch acceptance and exportable agent state.
- Ignore: raw reach as proof of adoption, repository stars as retained usage, and claims whose canonical primary source cannot be verified. Baidu's ERNIE 5.5 Flash Base discussion was excluded because the primary release page could not be read.
