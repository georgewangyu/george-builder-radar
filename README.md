# George's Builder Radar

Follow builders who ship.

George's Builder Radar is a public feed from George's morning routine: X,
GitHub, Product Hunt, YC/HN launches, official AI/devtool blogs, and selected
podcasts.

It updates whenever George runs his morning routine. The repo keeps the public,
polished version. Private health, calendar, journal, email, and raw timeline
context stay out.

## One Command

```bash
mkdir -p ~/.codex/skills && git clone https://github.com/georgewangyu/george-builder-radar.git ~/.codex/skills/george-builder-radar
```

Then ask your agent:

```text
set up George's Builder Radar
```

The skill reads the latest markdown feed and turns it into a digest for your
chat, notes, or local markdown folder.

## Latest Feed
